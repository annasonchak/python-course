# Python Course

Repozytorium zawiera projekty realizowane w ramach zajęć. Każdy projekt znajduje się w osobnym katalogu i posiada własną dokumentację.

## Pobranie repozytorium

Przed rozpoczęciem pracy z jakimkolwiek projektem należy sklonować repozytorium za pomocą polecenia:

```bash
git clone https://github.com/annasonchak/python-course.git
```

i przejść do katalogu repo

```bash
 cd python-course/
```
Dalsze kroki są opisane w poszczególnych README.md projektów.
